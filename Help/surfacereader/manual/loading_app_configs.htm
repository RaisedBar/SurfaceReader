Loading Application Configurations

  1. Within the Surfaces list, highlight the control surface that you want to configure for use with a particular application.  Please note that you can have more than one surface in the list and each surface can be set to handle a different application.
  2. Bring up the Surfaces menu then select Load Application Configuration…
  3. Choose the application configuration that you require from the dialog box that appears.  Choosing the Default option will return your selected surface to SurfaceReader’s most basic configuration.
  4. SurfaceReader remembers the last loaded application configuration so, unless you change the music application that you're using, you won't need to use this dialog again, even if you quit SurfaceReader or shutdown your computer.
