Advanced Configuration

SurfaceReader provides two very sophisticated tools that allow you to configure how it interacts with your control surfaces:

  1. The Protocol Wizard, which allows you to define the MIDI messages that your control surface transmits and responds to. This wizard allows you to create new protocol definitions for control surfaces that we didn't have access to when we developed SurfaceReader. For example, you could train SurfaceReader to announce specific labels for buttons on your control surface using the Protocol Wizard.
  2. The Application Configuration wizard, which allows you to modify what happens when you press or move the controls on your control surface. By default, SurfaceReader announces the control label that was assigned using the Protocol Wizard when your surface's protocol definition was created, but different audio and music applications may override these defaults, making the default labels inappropriate. The Application Configuration Wizard allows you to define custom labels that suit a particular audio application, along with many other features.
