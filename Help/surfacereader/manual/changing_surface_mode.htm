Changing the Surface Mode

SurfaceReader provides four modes of operation, allowing you to change what happens when you use the controls on your surface.  The active mode can be set on a per-surface basis, so you can keep one surface in Live mode, whilst placing a second surface into ID mode.  The active mode for all of your configured surfaces is saved when you make a change, so your settings are preserved even if you close SurfaceReader.

You can select the active mode for a surface by highlighting it in the Surfaces list and choosing your desired mode from within the Surfaces menu, or you can use keyboard shortcuts from the Surfaces list.

The available modes are described below:

Live Mode

In Live mode the default behaviour is to announce the name of controls as you use them, along with any consequent display updates that are received from your application program.  This behaviour can be modified by creating an application configuration, as described in the Advanced Configuration section of this help system.

ID Mode

In ID mode your control surface’s hardware controls are disabled.  You can press buttons, turn knobs, etc. without affecting your application program.  Instead, you will hear the name of each control as you use it, allowing you to learn the layout of your surface’s front panel.

Screen-reader mode

This mode also prevents your surface’s hardware controls from performing their normal operations, but allows you to execute sequences of screen-reader commands that you can define in an application configuration.  This is a very complex feature, so it is described in-depth within the Advanced Configuration section of this guide.

Configuration Mode.

If you put a surface into Configuration Mode then shift your focus away from SurfaceReader and back to an application that you want to create an application configuration for, you can train controls in-place, allowing you to test your configuration as you go.

Keyboard Shortcuts.

The following shortcut keystrokes can be used to change mode whenever you have the Surfaces list in focus:

  • F3, Live mode.
  • F4, ID mode.
  • F5, Screen-reader mode.
  • F6, Configuration mode.
