Basic Configuration

SurfaceReader can support multiple control surfaces, even if they're using different control surface protocols. Your installed surfaces are shown in the Surfaces list, which is displayed in the main window of the application when you first run it. The Surface menu is used to perform all actions that relate to a single surface so, apart from when you want to add a new control surface, you will need to select the surface you want to configure in the Surface list before using any of the Surface menu options.
