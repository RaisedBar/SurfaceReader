Changing the MIDI Display Monitoring for Windows

  1. Highlight the control surface whose setup you want to change in the Surfaces list.
  2. Bring up the Surfaces menu then select Properties, followed by Display MIDI Setup. SurfaceReader will show a dialog box that allows you to specify the MIDI In and Out ports that will handle the messages transmitted by your application software back to your control surface.
  3. When the dialog box first opens you will be positioned on the MIDI In list, so use your up/down arrow keys to highlight the virtual MIDI In port that represents the other end of the virtual cable your software is using as its MIDI Out (for example, highlight MIDI-Yoke In 2 if your application’s MIDI Out is set to MIDI-Yoke Out 2).
  4. Press Tab to get to the MIDI Out list and highlight the MIDI Out port that your control surface is physically attached to.  This output port will be used to pass your application’s MIDI messages back to the display elements of your control surface (i.e. its LED lamps and/or text displays).
  5. Press Tab until you get to the OK button and press Enter to leave the dialog box.

Changing the MIDI Display Monitoring for Mac

  1. Highlight the control surface whose setup you want to change in the Surfaces list.
  2. Bring up the Surfaces menu then select Properties, followed by Display MIDI Setup. SurfaceReader will show a dialog box that allows you to specify the MIDI Out port that will handle the messages transmitted by your application software back to your control surface.
  3. Select the MIDI Out port that your control surface is physically attached to from the table.  This output port will be used to pass your application’s MIDI messages back to the display elements of your control surface (i.e. its LED lamps and/or text displays).
  4. Press Tab until you get to the OK button and press Enter to leave the dialog box.
