Renaming Controls
To rename a control within the Application Configuration wizard:
  1. Select a control name within the tree view.
  2. Tab to the Rename button and press Enter.
  3. A dialog box will appear prompting you for a new control name. Type the new name in the edit box, press Tab to get to the OK button and press Enter.
  4. The wizard will check that the new name is unique and warn you if it is not, so that you can try again. If your new name is unique, you'll be returned to the tree view, focused on the selected control and its new name.
