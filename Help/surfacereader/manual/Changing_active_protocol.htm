Changing the active protocol.

To change the protocol that your control surface is using:

  1. Change the active protocol or memory preset on your control surface hardware using the manufacturer's instructions.
  2. Select the surface in the Surface list that you want to change.
  3. Go to the Surface menu.
  4. Select the Properties sub-menu.
  5. Select Protocol.
  6. Pick the protocol definition that you want to use from the list.
  7. Tab to the OK button and press Enter.
