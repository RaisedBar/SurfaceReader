Miscellaneous Functions

V-Pot clicks.

The difference between a normal rotary control and a V-Pot is that a V-Pot combines the functionality of a normal rotary control with that of a button. This means that you can press down on a V-Pot, just like a normal button. In Sonar such V-Pot clicks are set to reset the parameter that the V-Pot is currently controlling to some default value. For Example, if your V-Pots are controlling panning, pressing one of them will reset the pan position to the centre.

Keyboard functions.

There are some more keyboard shortcuts which have BCF2000 equivalents.  I don’t think they are that useful as control surface functions, but they are listed here for the sake of completeness.  If you don’t want to move between the keyboard and control surface quite so often, this section is for you.

  • You can assign a number of different functions to Upper Shift+Mute 1-Mute 8 in the Mackie Control Dialog, found on the Tools Menu.
  • M1+Upper Shift+Select 1 performs a Cut.
  • M1+Upper Shift+Select 2 is copy
  • M1+Upper Shift+Select 3 is paste.
  • M1+Upper Shift+Select 4 is delete.
  • M1+Upper Shift+Select 5 is space.
  • M1+Upper Shift+Select 6 is ALT.
  • M1+Upper Shift+Select 7 is TAB.
  • M1+Upper Shift+Select 8 is back (Shift+Tab.
  • Lower Shift+Bank Left is Undo, the same as selecting Undo from the Edit menu.  Lower Shift+Bank Right is Redo.
  • Lower Shift+v-pot1 inserts a new audio track.
  • Lower Shift+v-pot 2 inserts a new MIDI track.
  • Lower Shift+v-pot3 fits tracks to view.
  • Lower Shift+v-pot4 fits project to view.
  • Lower Shift+v-pot5 activates the OK button in dialogs.
  • Lower Shift+v-pot6 activates a dialog’s Cancel button.
  • Lower Shift+v-pot7 goes to the next window (like Control+Tab).

Lower Shift+v-pot8 closes the current window (like Control+F4).
