Using a Behringer BCF2000

Sonar

The following notes are intended for use by the blind or visually-impaired user, or by those who want to use the BCF2000  without relying on the visual display.  The actual display contents will be given throughout this document, though, just in case you have a handy sighted person around.

This guide is not a substitute for reading the official documentation, but is intended as a useful supplement to it.  We hope these notes get you up and running quickly using your BCF2000 with Cakewalk Sonar.
