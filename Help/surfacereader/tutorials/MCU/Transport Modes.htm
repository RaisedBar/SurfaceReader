Transport Modes

Similar to how switching Sonar mode changes what is assigned to the v-pots , switching Transport modes changes how the Rewind and Fast Forward buttons respond.  The transport controls are the Rewind, Fast Forward, Stop, Play and Record buttons.  These are the bottom five large buttons on the right-hand panel and the Record button has a tactile vertical bar to either side of it.

There are five Transport modes available.  Play is the default.  The remaining four are marker, select, loop and punch.  These modes  are covered below.  You can jump directly from one transport mode to another - you don’t have to enter and exit each mode.

Play Mode

Play mode is active by default.  Press Play to start playback.  Press Play again to pause, so Play is a simple toggle.  Press Stop to stop and rewind to your last start position.  Press Rewind to move backwards by one measure and Fast Forward to move forward by the same amount.  The resolution for the rewind and fast forward functions is set in the Mackie Control dialog within Sonar's Tools menu, and can be set to measures, beats or ticks (measures is the default).  Press M1+Rewind to go to the beginning of the project.  Press M1+Fast Forward to go to the end of the project.

Press Record to start or stop recording.  You must first select and arm at least one track before recording.  Remember, you can do this by pressing the Arm button(s) on any strip.  So, press Arm to arm a track or tracks, then Record to start and stop recording.

Marker Mode

Marker mode is for inserting and navigating among markers in a project.  Pressing the Marker button takes you into Marker Mode.  The Rewind and Fast Forward buttons now move you between any previous and next markers.  M1+Rewind still takes us to the project start and M1+Fast Forward still takes us to its end.  M1+Marker Mode inserts a marker at the current position, and works in any Mackie Control Universal mode.

Select Mode

In select mode, we can use the transport controls to set from and through times, and select tracks.  To jump to Select mode, press the Select Mode button above the transport buttons.  Rewind and Fast Forward now jump to the from and through times, if they are set.  Add M1 to your Rewind and Fast Forward button presses in order to set the from and through times, respectively.

Here is an example.  Let’s say we want to select from measure 10 to measure 30 in our project.  Assuming you are in Play mode, use Rewind/Fast Forward to get to measure 10.  Press Select Mode to enter Select mode.  Press M1+Rewind to set the from time.  Press Select Mode again to exit Select mode and return to Play Mode.  Press Fast Forward to get to measure 30.  Pressing Select Mode again re-enters Select mode, and then pressing M1+Fast Forward sets the Through time at measure 30.  Try this a few times and it will soon become as natural as JSonar or CakeTalking keystrokes.

Once the From and Through times are set, press Select Mode to toggle between selecting and deselecting the area between them.  If you don’t have From and Through selected, Select Mode selects the entire track.

TIP: Set up one of your function buttons (F1-F8 in the Mackie Control dialog) to “select none”, to cancel From and Through times.

Loop Mode

Press Loop Mode to enter and exit Loop mode.  Rewind and Fast Forward now jump to the start and end loop points, if they are defined.  Press M1+Rewind to set the loop start point, and M1+Fast Forward to set the loop end point.  Remember to go into Play mode before using Rewind  and Fast Forward to move from measure to measure, then back into Loop mode with Loop Mode before setting your loop’s start or end points.

From any mode, press the Loop On/Off button to toggle the loop on and off.

You can also press M2+Loop Mode to set the loop boundaries to any selected area.

Pressing M3+Undo rejects your last loop recording.

Finally, from any mode, press M1+Loop Mode to open the Loop/Auto Shuffle dialog box.

Punch Mode

Press Punch Mode to enter and exit Punch mode.  The Rewind and Fast Forward buttons now jump to the punch in and out points, if they are set.  Press M1+Rewind to set punch in, and M1+Fast Forward to set punch out.

IMPORTANT: when you Set your second punch point, be it punch in or punch out, you will automatically ready the marked punch area for recording.  As in other transport modes, you need to first exit Punch mode with the Punch Mode button before using rewind and fast forward for their normal functions.

M2+Punch Mode sets the punch in and out points to any selection you may have in place.

In any mode M2+Record opens the Record Options dialog box.

TIP: Set one of your function buttons to toggle the punch region selection status.
