EQ Mode - Controlling Equalizer Parameters.

Many MCU users don’t explore beyond what we have covered so far.  This is unfortunate, since adjusting equalizer parameters with physical controls is far more intuitive than using keyboard hotkeys which adjust things in discrete steps.  Adjusting EQ with actual v-pots and faders is probably as useful to us as automating volume and pan movements.  The Multi and Single mode principle applies when adjusting EQ as well, and we will cover Multi mode first.

EQ Multi Mode

Press the EQ Mode button once and the Assignment display should read “E1”.  If it reads “E1.” With a period instead, press the Track Mode button to get back into Multi mode.  In E1 Multi, your v-pots now control a parameter each, one parameter for each of eight track’s or bus’ EQ.  By default, the parameter assigned to your v-pots is Band 1 frequency.

TIP: A little forethought and planning can make this mode more useful during a mixing session than it first appears.  If you always use band 1 of the per track or bus EQ to control low frequencies, with a shelf or cut type filter, this mode is a handy way to adjust that particular aspect of your tracks and busses.

To change which parameter is assigned to the v-pots, go into Edit mode with the Edit button.  Use Bank Left and Bank Right to move by groups of eight parameters, or press Channel Left or Channel Right to switch by one parameter at a time.  The parameter order is: bands 1-4 frequency, bands 1-4 Q, bands 1-4 gain, bands 1-4 on/off, bands 1-4 filter type, and, finally, EQ on/off.

EQ Single Mode

EQ Single is more useful then EQ Multi in most situations.  Press EQ Mode  again (your second press).  The Assignment display reads “E1.”  Note the period.  The v-pots now control eight EQ parameters for the currently selected track or bus.  You can now control all four EQ band frequencies, q values, gains, enable/disable and filter type controls.  Please note:  you cannot change the order of these parameters without editing the MackieControl.ini file (see below), but you can step through them in the usual way, with Channel Left and Channel Right.  The parameter order is the same as in the previous section, EQ Multi, described above.

EQ Fader Mode

EQ is the only situation where we have a third Mackie Control Universal mode available to us.  Press the EQ Mode button a third time and the Assignment display shows “F1”.  Your left-most four faders now control the gain control for EQ bands 1-4, while the corresponding v-pots control bands 1-4 frequency.  This is the most intuitive set-up for fine-tuning the per track or bus EQ.  Press the Track Mode button twice to return to track Multi.
