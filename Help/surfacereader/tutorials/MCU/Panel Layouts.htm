Front Panel

The front panel is laid out in the same way for both models, though the buttons on the newer Mackie Control Universal Pro units are rectangular instead of round and are somewhat smaller.  The panel is organized into two sections, one which fills most of the unit’s surface area is arranged as eight vertical channel strips.  These are similar to the channel strips on a traditional mixing console.  The other panel of buttons and status LED’s occupy the right-hand side of the unit  The main LCD display is on the raised area above the strips and the Assignment and Time displays are to its right.

Enabling Communication Between Mackie Control Universal and Sonar

It is very important to Always turn on the Mackie Control Universal and load SurfaceReader before starting Sonar. You should also turn the Mackie Control Universal off after you exit Sonar or just leave it switched on all the time.  Failing to follow this procedure will require you to perform some of the following steps again to re-enable communication.

To get Sonar and the Mackie Control Universal communicating with each other:

Selecting Mackie Control Mode On The Mackie Control Universal

The Mackie Control units can support the Logic Control and HUI control surface protocols, but Sonar will only support the Mackie Control if it is set up to use its native Mackie Control protocol.  If you’ve never changed your unit’s active protocol, then you will already be set up correctly, as the Mackie Control protocol is the default setting.  The method for changing the protocol being used is as follows, but having some sighted help will probably be a good idea:

  1. Turn off the Mackie Control.
  2. Press and hold the Select buttons on channels 1 and 2, then turn on the Mackie Control (keep holding the 2 buttons).
  3. The faders will dance, then the "Select Operating Mode" prompt will appear on the display.
  4. Press the V-Pot on Channel 1 to enter Mackie Control Mode, or on Channel 4 to enter HUI Mode.

The Mackie Control will "remember" which mode you were last using, so you only need to perform this procedure when you're changing from one operating mode to the other.

Selecting the Control Surface In Sonar

You need to add your Mackie Control to Sonar’s configuration by doing the following:

  1. From within Sonar, bring up the Options menu.
  2. Highlight the Controllers/Surfaces menu option and press Enter.
  3. Tab to the Add Surfaces button, then press Enter  to bring up a list of available surfaces.
  4. Highlight Mackie Control within the list.
  5. Press Tab and make sure the correct virtual input and output ports are selected to match your settings within SurfaceReader.
