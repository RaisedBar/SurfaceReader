Sends Mode

In Sends Mode the V-pots control any auxiliary sends on your tracks/buses.

Sends Multi Mode

Press the Sends Mode button once.  The Assignment display should now read “SE”, and your v-pots are now set to control Send 1 volume for eight tracks or busses.  To change this parameter assignment, go into Edit mode, and use the bank Left/Right and Channel Left/Right buttons to assign the v-pots to a different Send parameter.  For instance, the previous parameter is Send 1 on/off.  The next parameter is Send 1 Pan.  If you have more than eight sends, you can jump to them using the bank up/down buttons.  Press the Track Mode button twice to return to track multi.

Sends Single Mode

In Sends Single Mode, your v-pots control all aspects of a single selected track or bus’ auxiliary sends.  Pressing the Sends Mode button from Sends Multi Mode gets you into Sends Single Mode.
