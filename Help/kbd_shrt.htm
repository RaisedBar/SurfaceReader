Keyboard Shortcuts

Surface List.
The following keystrokes are defined when you are focused on the Surface list.
KeystrokeFunction
DeleteRemoves the selected surface.
F1Displays the Help system's Table of Contents.
F2Renames the selected surface.
F3Puts the selected surface into Live mode.
F4Puts the selected surface into ID mode.
F5Puts the selected surface into Screen reader mode.
Alt+EnterEdits the selected surface's protocol (same as choosing Surfaces>Properties>Protocol from the menu system).
Control+EnterShows a report detailing the current state of all of the displays defined for the selected surface.
